10件の質問

「ollamaは認識されません」と表示される
  1. STEP 2の公式コマンドで、インストールが完了したか確認します。
  2. PowerShellとVS Codeをすべて閉じ、開き直します。アプリの場所を読み直すためです。
  3. スタートメニューからOllamaを起動し、次を試します。
入力先：PowerShell · バージョンを確認
ollama --version

改善しなければ公式Windows手順でインストール先を確認します。出所不明の修復スクリプトは実行しません。

STEP 2へ戻る →
Ollamaが起動しない・接続できない

スタートメニューからOllamaを開きます。アプリの画面を閉じてもバックグラウンドで動く場合があります。次で応答を確認します。

入力先：PowerShell · ローカル接続を確認
(Invoke-WebRequest -Uri 'http://127.0.0.1:11434' -UseBasicParsing).Content

「Ollama is running」なら起動しています。接続先は http://127.0.0.1:11434 のままにします。ファイアウォールをすべて無効にしたり、外部へ公開したりしません。

起動直後に終了する場合は、GPUの公式対応・ドライバーと %LOCALAPPDATA%\Ollama\server.log を確認します。公式トラブルシューティング ↗

STEP 2へ戻る →
モデルのダウンロードが進まない

回線接続と保存先の空き容量を確認します。数値が更新されていれば待ちます。長く変わらずエラーが出る場合は Ctrl + C で止め、同じコマンドを再実行します。

入力先：PowerShell · 選択モデルの取得を再試行
ollama pull qwen2.5-coder:1.5b

学校・会社の回線では、管理者がダウンロードを制限していることがあります。制限を回避せず、管理者に確認します。VPNやプロキシを使っている場合は公式FAQを確認してください。

STEP 3へ戻る →
メモリ不足になる・PCが重くなる
  1. 使っていないアプリ・ブラウザタブを閉じます。
  2. タスクマネージャーでRAMの使用状況を見ます。
  3. 無料モデルのページで1.5Bなど小さなモデルを選び直し、取得・Continueの設定を更新します。
  4. 会話を新しくし、長いコードや大量のファイルを渡さないようにします。

RAMが8 GB未満の場合は標準コースの対象外です。0.5Bも動作保証はありません。PCが不安定になる場合は、作業を中断してください。

モデルを選び直す →
VS Code / Continueからモデルが見つからない

まず、PCにモデルが保存されているか確認します。

入力先：PowerShell · 保存モデルの一覧
ollama ls

一覧のNAMEと、Continueの config.yaml にある model: をコロン以降まで完全に一致させます。例：qwen2.5-coder:1.5b。Ollamaを起動し、ContinueのMain Config（旧版ではLocal Config）とLocal Coderを選びます。設定を保存しても反映されなければ、設定選択欄の「Reload」を押します。モードはChatにします。

YAMLエラーなら、タブや空白のずれ、同じ設定の二重貼り付けがないか確認します。設定例はPowerShellに実行するものではありません。

接続設定を見直す →
AIの回答が非常に遅い

最初の回答ではモデルの読み込みに時間がかかります。長文を避け、短い質問で確認します。回答中に次を実行すると、CPU/GPUの使用状況を確認できます。

入力先：PowerShell · 実行状況を確認
ollama ps

CPUでの処理は遅くなる場合があります。GPUがあっても、対応やドライバー次第です。公式GPU対応を確認し、まず小型モデルと短い会話で試します。一定の速度は保証できません。

ContinueのAPI Key・サインインの案内から進めない

Continue 2.0.0で確認した初回のAPI Key画面では、キーを入力せず、Continue上部の歯車→「Configs」→「Main Config」の歯車からローカル設定を開けます。STEP 4の設定手順を確認してください。旧版ではLocal Configという名前の場合があります。

本サイトでは現在のクラウドアカウントの規約・年齢条件を確認できていないため、アカウント作成は案内していません。認証を回避するプログラムや他人のアカウントは使わないでください。

エディター連携をいったん待ち、取得済みのモデルとPowerShellで会話を試すこともできます。起動後は入力欄に質問を書き、終了するときは /bye を入力します。

入力先：PowerShell · 対話を開始（導入済みモデル）
ollama run qwen2.5-coder:1.5b
入力先：Ollamaの対話画面 · 会話を終了
/bye
作ったHTMLが開けない・コードがそのまま出る

ファイル名が index.html か確認します。index.html.txt なら拡張子を直します。AIの回答からコピーするときは、説明文やコードを囲む ```html を除き、HTML本体だけを保存します。

VS Codeで保存し、エクスプローラーからEdge / Chromeで開きます。内容を変えたときはブラウザも更新してください。短い完成例と比べられます。

本当に無料？ 入力は外部に送られない？

本コースのOllamaローカルモデルの推論にはAPI利用料がありません。電気代・通信費・機器の費用は別です。有料クラウドサービスへ切り替えた場合は、その料金条件が適用されます。

この設定での推論先はPC内です。Ollamaのクラウド停止、ContinueとVS Codeのテレメトリーも確認してください。モデル取得・ソフト更新・認証などの通信までなくなるわけではありません。

LLM STARTのコードは、選択項目やAPIキーをサーバーに送信しません。サイトのデータ方針と安全設定を確認できます。

進捗が保存されない・リセットしたい

進捗はこの端末・このブラウザのlocalStorageに保存します。別のブラウザやURLには引き継がれません。プライベートブラウズ、サイトデータの削除、ブラウザの制限で失われることがあります。

保存が使えない場合は画面上に案内します。ファイルを直接開くと保存の挙動がブラウザにより異なるため、安定した確認にはREADMEのローカルサーバー手順を使ってください。

消したい場合はガイドの「進捗をリセット」を開き、「チェックをリセットする」を押します。モデル設定は残ります。
