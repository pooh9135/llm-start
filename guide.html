STEP 01 / 07 PCの準備

自分のPCスペックを確認する

まずは「どんなPCを使っているか」を調べます。
ソフトを入れる前に確認すると、無理のないAIを選べます。

◎
このステップのゴール

Windowsのバージョン・CPU・RAM・GPU・VRAMが分かる。

1Windowsのバージョンを確認

Windows + R を押し、「ファイル名を指定して実行」に次の文字を貼り付けて Enter を押します。

入力先：ファイル名を指定して実行
winver

開いた画面で「Windows 11」などの名前とバージョンを見ます。Ollamaの公式条件はWindows 10 22H2以降です。Windows 10では、サポート状況・延長セキュリティ更新も確認し、更新が受けられるPCを使ってください。

2タスクマネージャーを開く

Ctrl + Shift + Esc を同時に押します。簡易表示なら「詳細」を開き、左側または上部の「パフォーマンス」を選びます。

CPU
「CPU」を選び、右上の製品名を確認します。AIの処理速度に関わります。
RAM
「メモリ」の右上の総容量を確認します。「使用中」の値とは違います。
GPU
「GPU 0」「GPU 1」を選び、右上のGPU名を確認します。複数あるPCは両方を見ます。
VRAM
GPU画面の下にある「専用GPUメモリ」の上限を確認します。例：1.0 / 8.0 GBなら8 GB。「共有GPUメモリ」は足しません。項目がなければ「専用GPUなし／不明」で進めます。

3保存先の空き容量も確認

Windows + E →「PC」で、Cドライブなどの空き容量を確認します。Ollama本体に少なくとも4 GB、さらにモデルと作業用の空きが必要です。本コースでは軽量モデルでも合計10 GB以上の空きを目安に、余裕を用意してください。

分からない項目があっても大丈夫。

このコースは軽量モデルから始めます。モデルを変更したい場合だけ、無料モデルのページを確認してください。このサイトがPCのスペックを自動取得することはありません。

STEP 02 / 07 作業場所を準備

VS Codeをインストールする

VS Codeは、コードを書くための無料エディター。
メモ帳のようにファイルを開き、編集できるアプリです。

◎
このステップのゴール

日本語のVS Codeで、練習用の空フォルダを開く。

1公式サイトからダウンロード

WindowsのUser Installer（ユーザー用）を選びます。通常のIntel・AMD製PCはx64、ARM搭載PCはArm64です。不明ならWindowsの「設定」→「システム」→「バージョン情報」→「システムの種類」を確認します。

VS Code公式ダウンロード ↗

2インストーラーを実行

ダウンロードした VSCodeUserSetup-…exe を開き、利用条件を読んで進めます。ユーザー用は管理者権限が不要です。完了したらVS Codeを起動します。すでに導入済みなら、次の確認へ進めます。

Copilotの案内が出たら？

このコースでCopilotの契約は不要です。インストール時に「Don't add the copilot command」が出たら選んで構いません。Continueは後で別に追加します。

3表示を日本語にする

  1. Ctrl + Shift + P で「コマンドパレット」（機能を探す入力欄）を開きます。
  2. Configure Display Language と入力して選びます。
  3. 日本語（ja）を選びます。言語パックのインストールが必要なら進め、再起動の案内を選びます。

見つからない場合は拡張機能で「Japanese Language Pack」を検索し、発行元がMicrosoftのものを確認します。

4練習用のフォルダを開く

  1. エクスプローラーで「ドキュメント」を開き、新しいフォルダ llm-practice を作ります。
  2. VS Codeの「ファイル」→「フォルダーを開く」から、そのフォルダを選びます。
  3. 信頼を尋ねられたら、自分で作った空の練習フォルダであることを確認して許可します。知らない人のフォルダは安易に信頼しません。

✓ 左のエクスプローラーに「LLM-PRACTICE」と表示されれば準備できています。

STEP 03 / 07 AIのエンジンを準備

Ollamaをインストールする

Ollama（オラマ）は、モデルをPCに保存して動かすアプリ。
VS Codeとは別にインストールします。

◎
このステップのゴール

Ollamaのバージョン番号と、起動していることを確認する。

1Windows用をダウンロードして実行

公式ページで「Download for Windows」を選び、OllamaSetup.exe を実行します。案内に沿ってインストールすると、Ollamaはバックグラウンドで動きます。

Ollama公式ダウンロード ↗

このコースではローカルモデルを使います。クラウドモデルの選択、APIキーの発行、支払い登録は必要ありません。

2PowerShellを開く

Windowsのスタートメニューで「PowerShell」と検索し、通常の方法で開きます。PowerShellは、文字でPCに指示を出すアプリです。管理者として開く必要はありません。

インストール前から開いていた場合は、開き直します。

新しく追加されたOllamaの場所を、PowerShellが読み込み直すためです。

3バージョンと起動を確認

次のコマンドをPowerShellに貼り付け、Enter を押します。これはバージョンを表示するだけです。

入力先：Windows PowerShell
ollama --version

✓ 「ollama version …」のように番号が表示されれば、コマンドを使えています。

次はローカルのアプリが応答するか確認します。外部サイトには接続しないコマンドです。

入力先：Windows PowerShell · 起動を確認
(Invoke-WebRequest -Uri 'http://127.0.0.1:11434' -UseBasicParsing).Content

✓ 「Ollama is running」と表示されれば成功です。

接続エラーならスタートメニューからOllamaを起動し、もう一度確認します。起動しない場合の対処も参照できます。

STEP 04 / 07 モデルを準備

AIモデルをダウンロードする

まずは軽量な1.5BモデルをPCに保存します。無料モデルのページで変更済みの場合は、その選択を使います。
初回はインターネット接続と、十分な空き容量が必要です。

◎
このステップのゴール

モデル一覧に qwen2.5-coder:1.5b が表示される。

1VS Codeでターミナルを開く

VS Codeの上部メニュー「ターミナル」→「新しいターミナル」を選びます。ターミナルは、文字のコマンドを入力するための画面です。下部のパネルにPowerShellと表示されているか確認します。

別の名前なら、ターミナル右上の「＋」の横のメニューからPowerShellを選びます。STEP 3で使ったWindows PowerShellでも同じ操作ができます。

ターミナルPowerShell

PS C:\…\llm-practice>

「>」の後が入力場所。先頭の「PS C:\…>」はコピーしません。

2モデルを取得する

「コピー」を押し、ターミナル内をクリックして Ctrl + V、続けて Enter。pull は「モデルをダウンロードする」操作です。

入力先：VS CodeのPowerShell
ollama pull qwen2.5-coder:1.5b

現在の選択：qwen2.5-coder:1.5b · 配布ファイル 986 MB。必要な場合だけモデルを変更する

進捗の数値が変わっていれば待ちます。「success」と表示され、入力待ちに戻れば完了です。時間は回線とモデル容量によって変わります。

3保存されたモデルを確認

list は、PCに保存済みのモデル一覧を表示します。

入力先：VS CodeのPowerShell
ollama list

✓ NAME欄に qwen2.5-coder:1.5b があれば準備完了です。

よくあるエラーと対処
  • 「認識されません」：PowerShellとVS Codeを開き直します。詳しい対処
  • 接続できない：スタートメニューからOllamaを起動します。
  • ダウンロード停止：空き容量・回線を確認し、同じpullコマンドを再実行します。詳しい対処

公式出典：Ollama CLI ↗ · モデルのタグ・容量 ↗ · 確認日 2026-11-06

STEP 05 / 07 AIとの接続

VS CodeとAIを接続する

Continue（コンティニュー）という拡張機能を使い、
VS Codeの中でローカルAIに質問できるようにします。

◎
このステップのゴール

ContinueのChatで、Local Coderから返事が届く。

1公式のContinue拡張機能を入れる

VS Codeで Ctrl + Shift + X を押し、拡張機能を開きます。公式リンクから開くか、Continue.continue を検索して発行元・識別子を確認し、「インストール」を選びます。

Continue公式拡張機能 ↗

左のContinueアイコンを開きます。初回の表示は版によって異なります。ローカル設定（Local Config）を使い、クラウドのモデルや課金用のAPIキーは追加しません。

サインイン画面が出て先へ進めない場合

「Skip」「Local」などローカル利用の選択肢があるか確認します。見つからない場合は、公式が案内するオフライン設定の経路もあります。

  1. 公式GitHub Releasesを開き、拡張機能のリリースにある「Assets」から、自分の環境に対応する .vsix を取得します。CLIの配布物とは別です。
  2. VS Codeの拡張機能画面の「…」メニュー→「VSIXからのインストール」を選び、取得したファイルを指定します。
  3. VS Codeのユーザー設定で「Continue: Allow Anonymous Telemetry」をオフにし、下のconfig.yamlをローカルモデルで設定して再起動します。

Continue公式オフライン手順を確認しながら進めてください。現行のクラウドアカウントの規約・年齢条件は本サイトでは確認できていません。ローカル設定に切り替えられない版では登録を急がず、PowerShellで会話を試す案内を使えます。

2Local Configを開いて設定する

Continueのモデル選択や設定の歯車からLocal Configのconfig.yamlを開きます。見つからないときは、VS Codeの「ファイル」→「ファイルを開く」で、ファイル名に %USERPROFILE%\.continue\config.yaml を入力します。まだファイルがなければ、エクスプローラーのアドレス欄で %USERPROFILE% を開き、.continue フォルダと config.yaml を作成します。

エクスプローラーで作る場合は「表示」の中の「ファイル名拡張子」をオンにし、config.yaml.txt になっていないか確認します。VS Codeで新規保存するときは、ファイルの種類を「すべてのファイル」にして正確な名前を付けられます。

初回の練習用設定なら、次を貼り付けて Ctrl + S で保存します。既存の設定がある人は、コピーを残してから編集してください。空白の字下げをそのまま保ち、タブは使いません。

貼り付け先：config.yaml（PowerShellではありません）
name: My Local AI
version: 1.0.0
schema: v1
models:
  - name: Local Coder
    provider: ollama
    model: qwen2.5-coder:1.5b
    apiBase: http://127.0.0.1:11434
    roles:
      - chat
    defaultCompletionOptions:
      contextLength: 4096

127.0.0.1 は「このPC自身」のこと。APIキーは不要です。まずChatだけを使い、会話の長さを4,096トークンに抑えて負荷を増やしすぎない設定にしています。

3モデルを選んで接続を確認

  1. VS Codeを一度再起動し、練習フォルダとContinueを開きます。
  2. 設定がLocal Configであることを確認し、モデルでLocal Coderを選びます。モードはChatにします。
  3. チャットの入力欄に「こんにちは。短く日本語で返事してください」と送り、返事が出るか確認します。

✓ 返事が出れば接続成功です。内容や速度はモデルとPCによって違います。

「モデルが見つからない」なら、一覧と設定名の確認へ。Ollamaが起動していることも確認してください。

VS Code自体にもOllama連携はありますか？

2026-11-06に確認したVS Codeの公式文書では、内蔵Ollamaプロバイダーは非推奨となり、Ollamaチームの公式拡張機能への移行が案内されています。本コースでは手順を統一するためContinueを使います。別の経路の対応条件を混ぜないようにしましょう。

STEP 06 / 07 はじめの作品

AIで自己紹介ページを作る

短いお願いを送り、コードをファイルに保存します。
今回はHTMLだけ。追加のプログラミング環境はいりません。

◎
このステップのゴール

自分で保存したindex.htmlを、ブラウザで開く。

1ContinueのChatにお願いを書く

入力先はContinueのチャット欄です。PowerShellには貼り付けません。Local Coder・Chatを選んでいることを確かめて、次を送ります。

入力先：ContinueのChat
HTMLで簡単な自己紹介ページを作ってください。
名前は「たろう」、趣味は「読書」としてください。
見出しと短い紹介文を入れてください。
外部通信・JavaScript・外部ライブラリを使わず、
index.htmlひとつで開ける完成したHTMLを出してください。

本名や住所は使わず、練習用の名前にします。モデルによっては回答が不完全なことがあります。うまくいかなければ「もっと短いHTMLで、最初から最後まで書いて」と頼んでみましょう。

2生成コードを保存する

  1. 返信のコードを読み、不要な外部URLやスクリプトがないか見ます。分からなければ「このコードに外部通信やJavaScriptはありますか」と質問します。
  2. VS Code左の練習フォルダで「新しいファイル」を選び、index.html と名前を付けます。
  3. AIの返信のうち <!doctype html> から </html> までをコピーし、作ったファイルに貼り付けます。前後の説明や ```html の囲みは含めません。
  4. Ctrl + S で保存します。拡張子が .html.txt にならないよう確認します。

3ブラウザで開いてみる

VS Codeのファイルを右クリック→「エクスプローラーで表示」。エクスプローラーで index.html をダブルクリックし、EdgeやChromeで開きます。文字と見出しが見えれば成功です。

内容を直したら、VS Codeで保存し、ブラウザを Ctrl + R で更新します。この操作だけではインターネットに公開されません。

✓ 「たろう」や「読書」が画面に出れば、最初の作品ができました。

表示されない場合に比べられる、短い完成例も用意しています。これは本サイトが用意した見本で、AIの出力例を保証するものではありません。

提案は、実行する前に確認。

今回は手動でコピーして保存します。Agentモードや「すべて許可」でファイル変更・コマンド実行を任せる必要はありません。仕事のフォルダや秘密情報を使わず練習しましょう。

STEP 07 / 07 最後のチェック

安全設定と最終確認

これからも安心して使えるように、
接続先・料金・情報の扱いを確かめます。

◎
このステップのゴール

ローカルモデルを選び、安全に使うための設定を確認する。

1Ollamaのクラウド機能を無効にする

ローカル利用だけにするため、次をPowerShellで実行します。このコマンドは自分のWindowsアカウントの環境変数を設定します。ソフトの追加・削除はしません。

入力先：PowerShell · 実行前に内容を確認
[Environment]::SetEnvironmentVariable('OLLAMA_NO_CLOUD', '1', 'User')

タスクトレイのOllamaアイコンから完全終了し、スタートメニューから起動し直します。新しい環境変数が反映されない場合はWindowsにサインインし直します。

Ollamaのログ %LOCALAPPDATA%\Ollama\server.log を開き、再起動後の Ollama cloud disabled: true を確認します。これはクラウドモデルとWeb検索を無効にする設定です。

設定を元に戻したいとき

Windowsの「ユーザー環境変数の編集」で OLLAMA_NO_CLOUD を削除し、Ollamaを完全終了・再起動します。クラウド利用には別の条件が適用されます。

2接続先と通信の設定を確認

  • Continueの設定が provider: ollama、接続先が http://127.0.0.1:11434 で、選択したローカルモデルになっている。
  • Ollamaの接続先を外部に公開する変更をしていない。0.0.0.0 へ変更しない。
  • VS Codeの設定で「Continue: Allow Anonymous Telemetry」を検索し、匿名の利用状況送信を止めたい場合はオフにする。
  • VS Code自体の telemetry.telemetryLevel も、必要に応じて off にする。拡張機能には個別の通信設定がある。
ローカル推論と、アプリ全体の通信は別です。

この設定の推論はPC内で処理されます。一方、アプリの更新、拡張機能の認証、モデル取得などには通信が発生します。「PCから一切通信しない」とは保証していません。

3料金と秘密情報の扱いを確認

  • このコースでAPIキー・クレジットカードを登録していない。ローカルモデルの推論にはAPI従量料金がない。電気代・通信費・PC本体の費用は別。
  • モデル名に :cloud などクラウド向けの指定がない。無料のクラウド枠とローカル実行を混同しない。
  • 自分や他人のAPIキー、パスワード、個人情報をチャットや公開ファイルに貼らない。他人から渡されたキーを使わない。
  • AIのコード変更や実行提案は内容を見て許可する。分からないコマンドは実行しない。
将来APIキーを使うなら

APIキーはサービスを使うための秘密の合鍵です。HTML・JavaScript・GitHubの公開リポジトリに入れません。公開してしまったらファイルを消すだけでなく、提供元でキーを失効させます。ブラウザに配るコードでは秘密を隠せないため、本サイトの静的構成にはAPI接続を追加しないでください。

外部サービスのアカウント・APIには利用規約、地域・年齢条件、請求条件があります。公式条件の確認先を読み、今回のローカルコースとは別に検討します。

4最後にもう一度、動作を確かめる

ContinueでLocal Coder・Chatを選び、短い質問を送ります。回答中に次のコマンドを実行すると、動いているモデルとCPU/GPUの使用状況を確認できます。

入力先：PowerShell · 実行中のモデルを表示
ollama ps

選んだモデルが表示され、保存したHTMLも開ければ、基本の流れを確認できました。回答後しばらくたつとモデルがメモリから外れ、一覧が空になることがあります。
