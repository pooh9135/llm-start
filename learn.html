ローカルAIと、クラウドAI。

違いは、AIの「頭脳」がどこで動くかです。このコースは、PCの中で動かすローカルAIを使います。

比べる項目ローカルAIクラウドAI
処理する場所自分のPCサービス提供元のサーバー
用意するものソフト・モデル・PCの空き容量通常はネット接続とアカウント。APIではキー等
費用このコースのモデル推論にAPI料は不要。電気代・通信費等は別無料枠・月額・従量料金など、サービスごとに異なる
できることPCとモデルの性能に左右される使えるモデル・機能・上限はプラン次第
情報の扱いこの設定の推論先はPC内。ソフト全体の通信とは別入力が外部サービスに送られる。規約と保存方針を確認

ローカルで動くAIも、間違った説明や不完全なコードを出すことがあります。回答を確かめることは、どちらを使う場合も大切です。

よく出てくる言葉

LLMモデルAPIトークンRAMVRAMターミナルエージェント
LLM Large Language Model / 大規模言語モデル
たくさんの文章などから学び、入力された言葉の続きや返事を作るAIの一種です。説明文やコードを書けますが、正しさを保証する辞書や計算機ではありません。
AIモデル AIが学習したデータのまとまり
AIの「頭脳」にあたるもの。Ollamaはそれを動かすアプリ、Qwen2.5-Coderはそのアプリで使えるモデルの名前です。1.5BなどのBは、モデルの規模を表す単位で、GBというファイル容量とは違います。
ローカルAI 自分のPCで処理するAI
モデルを自分のPCに保存して使う方法です。最初の取得やソフトの更新にはネット接続を使います。ローカルモデルを選ぶだけで、アプリ全体の通信がなくなるわけではありません。
API / APIキー ソフト同士の窓口 / 秘密の合鍵
APIは、ほかのソフトに「これを処理して」と頼むための窓口です。クラウドAPIではAPIキーで利用者を識別し、料金が発生する場合があります。今回のOllamaの窓口はPC内にあり、キーは使いません。他人のキーを使ったり、自分のキーを公開したりしないでください。
トークン / コンテキスト 文章の数え方 / AIが一度に扱う範囲
トークンは文章を細かく分けた単位です。日本語の1文字＝1トークンとは限りません。コンテキストには質問・会話・返答などが入ります。長くすると必要なメモリも増えるので、最初は短い質問から始めます。
RAM PC全体で使う作業用メモリ
作業机の広さのようなものです。ブラウザやエディター、AIが共有して使います。ストレージの空き容量とは別物で、モデルを保存できてもRAM不足で動かない場合があります。
GPU / VRAM 計算を助ける装置 / その専用メモリ
GPUは多数の計算を並行して行う装置。対応していればAIの計算にも使えます。VRAMは主に専用GPU上のメモリです。内蔵GPUの「共有GPUメモリ」を専用VRAMとして数えません。容量だけで対応可否や速度は決まりません。
ターミナル / PowerShell 文字で操作する画面 / 指示を解釈するソフト
ターミナルは文字でコマンドを入力する場所、PowerShellはWindowsでその指示を扱うソフトです。VS CodeのターミナルでもPowerShellを開けます。知らないコマンドを貼り付ける前に、何をするかを確認します。
拡張機能 アプリに機能を追加するもの
ContinueはVS CodeにAIのチャット欄などを追加する拡張機能です。拡張機能自身がAIモデルというわけではありません。発行元と公式リンクを確認して入れましょう。
AIエージェント 道具を使って作業を進める仕組み
会話に答えるだけでなく、ファイル編集やコマンド実行などを提案・実施する仕組みです。どこまで任せるかは権限と設定によります。本コースはChatを使い、生成コードは人が確認して保存します。
